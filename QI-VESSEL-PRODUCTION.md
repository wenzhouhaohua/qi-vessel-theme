# QI Vessel Theme 1.0 — Production Foundation V5

This build replaces the screenshot-based homepage with real HTML content and responsive controls.

## Production principles
- Real browser-rendered typography; no text embedded in the full-page image.
- Desktop and mobile use the same semantic DOM with independent responsive layouts.
- Central sacred scene is a decorative visual asset; navigation, CTA, form and journey content remain interactive.
- Motion respects `prefers-reduced-motion`.
- Shopify section schema names remain within platform limits.

## Before launch
1. Configure a Shopify navigation menu in the section settings.
2. Upload a final licensed high-resolution priestess scene through the section image picker when available.
3. Connect `Secure reading API endpoint` only to a server-side HTTPS endpoint.
4. Test in iPhone Safari, Android Chrome and desktop Safari/Chrome.
5. Do not publish until form data handling and privacy copy have been reviewed.
